## 7. Observations

- 9 of 43 tables have no write path anywhere in `src/` or `scripts/`: accounts, verificationTokens, deleteRequests, productSpecifications, duplicateFlags, nonDuplicates, pipelineSnapshots, personSnapshots, attachments.
- 3 of 12 role permission flags — canExport, canApproveDelete, canResolveDuplicate — are seeded with values but read nowhere in application code.
- `src/lib/quotations.ts` is 1,965 lines, the largest file in `src/`.
- `/quotations/[id]/versions` has no `page.tsx`; only `/quotations/[id]/versions/[versionId]` exists.
- `sessions` is the only table with a literal hard-delete call in application code (authz.ts, two sites).
- quotationLines, quotationServiceLines, repReportSignals and commentMentions are hard-deleted on edit/removal; every other table is append-only or soft-updated.
- `messages/en.json` and `messages/ar.json` carry exactly 740 keys each, with none missing either direction.
- No TODO, FIXME, XXX or HACK marker exists anywhere in `src/`.
- `npm run build` inside the project's Docker image fails to collect page data for `/follow-ups`; `next build` on the host completes without error.
- companies.hasCreditTerms is a not-null boolean column no code path ever sets to true.
- `src/app/**` has no direct Drizzle calls — every write happens through a `src/lib/*.ts` function.
